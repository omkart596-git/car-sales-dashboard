# Car Sales Dashboard

## Overview
This project is an interactive Car Sales Dashboard created using Power BI/Tableau to analyze sales performance, trends, and regional insights for different car companies.

## Dashboard Features
- YTD Total Sales Analysis
- YTD Average Price Analysis
- Cars Sold Analysis
- Weekly Sales Trend
- Sales by Body Style
- Sales by Car Color
- Regional Sales Visualization
- Company Wise Sales Performance
- Interactive Filters

## Dashboard Preview

![Dashboard](Car%20sales%20dashboard-overview.png)

## Key Insights
- SUVs generated the highest overall sales.
- White colored cars had the highest demand.
- Chevrolet recorded the highest YTD sales among all companies.
- Sales showed major spikes during specific weeks of the year.
- Regional analysis helped identify high-performing dealer regions.

## Tools & Technologies Used
- Power BI / Tableau
- Excel / CSV Dataset
- Data Visualization
- Data Cleaning & Analysis

## Dataset Information
The dataset contains:
- Car company details
- Sales information
- Dealer regions
- Vehicle body styles
- Car colors
- Transmission and engine types

## Project Objective
The objective of this project is to analyze car sales performance and create an interactive dashboard that helps businesses make data-driven decisions.
